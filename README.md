# U.S. Macro Command Center

A GitHub Pages dashboard powered by FRED and refreshed automatically with GitHub Actions.

## What it tracks
Rates/Treasury, inflation, labor, growth, consumer, corporate profits, financial conditions/credit, liquidity, and fiscal indicators.

## Setup
1. Create a GitHub repository and upload these files.
2. In GitHub: **Settings → Secrets and variables → Actions → New repository secret**.
3. Name the secret exactly `FRED_API_KEY` and paste your FRED API key as the value.
4. Go to **Actions → Refresh macro data → Run workflow** once.
5. Go to **Settings → Pages → Build and deployment → Deploy from a branch**.
6. Select your default branch (usually `main`) and folder `/ (root)`.
7. Open the GitHub Pages URL GitHub provides.

## Automatic refresh
The included workflow runs at 12:15 UTC on weekdays. You can also run it manually from the Actions tab.

## Security
Never paste the FRED API key into `app.js`, `index.html`, or any committed file. Keep it only in the GitHub Actions secret.

## Data model
`data/latest.json` is generated by `scripts/update_data.py`. Each metric contains latest value, change, source metadata, and recent history used by the browser charts.

## Expand later
The updater is intentionally modular so BLS, BEA, and U.S. Treasury Fiscal Data endpoints can be added without redesigning the front end.
